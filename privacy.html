Politique de confidentialité

WS Elements · en vigueur le 13 octobre 2026

WS Elements est une application iPhone indépendante qui affiche les données de votre console WithSecure™ Elements. Elle est éditée par Florian Stillitano, développeur individuel (contact : florian.stillitano@wsecure.fr). L'app ne contient ni publicité, ni mesure d'audience, ni suivi publicitaire, et ne vend aucune donnée.

Données traitées sur l'iPhone

  • Clés API Elements (identifiant et secret) : stockées dans le trousseau iOS de l'appareil. Elles servent uniquement à interroger l'API WithSecure Elements (api.connect.withsecure.com).
  • Données de sécurité (appareils, incidents, détections, événements, journaux d'audit) : lues depuis l'API Elements, gardées en cache temporaire sur l'iPhone.
  • Face ID : géré par iOS ; l'app ne reçoit jamais de donnée biométrique.

Fonctions optionnelles, activées par l'utilisateur

Notifications push. Si vous les activez et choisissez une clé à surveiller, sont envoyés à notre serveur de notifications (Supabase, Union européenne, Irlande) : le jeton de notification de l'iPhone, la langue et la version de l'app, une clé Elements en lecture seule (chiffrée en AES-256 sur le serveur) et vos règles de notification. Le serveur interroge l'API Elements chaque minute et transmet les alertes via le service de notifications d'Expo et le service Apple Push Notification ; le titre d'une notification peut contenir un nom d'incident ou d'appareil. L'historique des notifications est conservé 30 jours ; un compte inactif depuis 90 jours est supprimé avec ses données. « Effacer toutes les données » retire immédiatement l'iPhone et ses clés du serveur.

Analyste IA. Si vous configurez un fournisseur avec votre propre clé (Anthropic, OpenAI, Google ou Mistral AI), les données de l'incident ou de l'appareil analysé (détections, lignes de commande, noms de fichiers, événements) sont envoyées à ce fournisseur, après votre confirmation. L'option « Pseudonymiser les données », active par défaut, remplace les noms de machines, d'utilisateurs et les adresses IP internes avant l'envoi. Avec Apple Intelligence (modèle sur l'appareil) ou le mode démonstration, rien ne quitte l'iPhone. Ces fournisseurs traitent les données selon leurs propres conditions.

VirusTotal. Pour vérifier un fichier, l'app envoie à VirusTotal (Google) son empreinte (hash), jamais le fichier lui-même ; l'analyste IA peut aussi y vérifier des domaines et adresses IP publics. Les réponses sont gardées 7 jours sur l'iPhone.

Mises à jour

L'app télécharge ses mises à jour depuis le service Expo (EAS Update), qui reçoit les informations techniques nécessaires (adresse IP, version de l'app).

Vos droits

Vous pouvez effacer toutes les données à tout moment depuis Réglages → Effacer toutes les données, ou demander l'accès, la rectification ou la suppression de vos données par e-mail. Vous pouvez aussi saisir la CNIL (cnil.fr).

Privacy policy

WS Elements · effective October 13, 2026

WS Elements is an independent iPhone app that shows the data of your WithSecure™ Elements console. It is published by Florian Stillitano, individual developer (contact: florian.stillitano@wsecure.fr). The app has no advertising, no analytics, no ad tracking, and sells no data.

Data processed on the iPhone

  • Elements API keys (ID and secret): stored in the device's iOS Keychain. They are only used to query the WithSecure Elements API (api.connect.withsecure.com).
  • Security data (devices, incidents, detections, events, audit logs): read from the Elements API, kept in a temporary cache on the iPhone.
  • Face ID: handled by iOS; the app never receives biometric data.

Optional features, turned on by the user

Push notifications. If you turn them on and choose a key to watch, the following is sent to our notification server (Supabase, European Union, Ireland): the iPhone's notification token, the app's language and version, a read-only Elements key (encrypted with AES-256 on the server) and your notification rules. The server queries the Elements API every minute and delivers alerts through Expo's push service and the Apple Push Notification service; a notification's title may contain an incident or device name. Notification history is kept 30 days; an account inactive for 90 days is deleted with its data. "Erase all data" immediately removes the iPhone and its keys from the server.

AI analyst. If you set up a provider with your own key (Anthropic, OpenAI, Google or Mistral AI), the data of the analyzed incident or device (detections, command lines, file names, events) is sent to that provider, after your confirmation. The "Pseudonymize data" option, on by default, replaces machine names, user names and internal IP addresses before sending. With Apple Intelligence (on-device model) or the demo mode, nothing leaves the iPhone. These providers process data under their own terms.

VirusTotal. To check a file, the app sends VirusTotal (Google) its hash, never the file itself; the AI analyst may also check public domains and IP addresses there. Answers are kept 7 days on the iPhone.

Updates

The app downloads its updates from the Expo service (EAS Update), which receives the technical information needed (IP address, app version).

Your rights

You can erase all data at any time from Settings → Erase all data, or request access to, correction or deletion of your data by email. You may also lodge a complaint with your data protection authority.
