WS Elements — Assistance

Application iPhone indépendante, compatible avec l'API de WithSecure™ Elements. Elle n'est ni éditée ni approuvée par WithSecure.

Démarrer

  • Dans le portail Elements, créez un client API (de préférence en lecture seule), puis copiez son identifiant et son secret.
  • Ouvrez l'app, saisissez-les : leurs droits sont détectés automatiquement. Le secret reste dans le trousseau de l'iPhone.
  • Les actions à distance (isolement, analyse, diagnostic…) demandent un client API en lecture et écriture, et une confirmation Face ID.

Questions fréquentes

Mes données quittent-elles l'iPhone ? L'app interroge directement l'API Elements. Les fonctions optionnelles (notifications, analyste IA, VirusTotal) sont décrites dans la politique de confidentialité.

Comment tout effacer ? Réglages → Effacer toutes les données : clés, cache, réglages, et inscription au service de notifications.

Les notifications n'arrivent pas. Vérifiez Réglages iOS → Notifications → WS Elements, puis Réglages de l'app → Notifications → Envoyer un essai.

WS Elements — Support

Independent iPhone app, compatible with the WithSecure™ Elements API. It is not published or endorsed by WithSecure.

Getting started

  • In the Elements portal, create an API client (read-only preferred), then copy its ID and secret.
  • Open the app and enter them: their rights are detected automatically. The secret stays in the iPhone's Keychain.
  • Remote actions (isolation, scan, diagnostic…) need a read and write API client and a Face ID confirmation.

FAQ

Does my data leave the iPhone? The app talks directly to the Elements API. Optional features (notifications, AI analyst, VirusTotal) are described in the privacy policy.

How do I erase everything? Settings → Erase all data: keys, cache, settings, and the notification service registration.

Notifications don't arrive. Check iOS Settings → Notifications → WS Elements, then the app's Settings → Notifications → Send a test.
